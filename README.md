**RASNetManager** هو برنامج مجاني (Freeware) مخصص لإدارة شبكات الميكروتك (MikroTik RouterOS) وتوليد كروت الهوتسبوت (Hotspot Vouchers) بسهولة وفاعلية، مع دعم ميزة التحديث التلقائي للنظام.

---

## ✨ المميزات الرئيسية (Features)

* 🆓 **مجاني بالكامل:** استخدام مجاني بدون أي رسوم اشتراك أو قيود على عدد الكروت.
* 🎫 **توليد الكروت بسهولة:** إنشاء كروت وباقات هوتسبوت بأرقام وحروف عشوائية مخصصة.
* ⚙️ **إدارة الباقات (Profiles):** التحكم في حدود الوقت (Time Limit) وحجم البيانات (Data Limit) والسرعات.
* 🔌 **اتصال مباشر عبر API:** مزامنة سريعة وآمنة مع أجهزة الميكروتك عبر المنفذ `8728`.
* 🔄 **التحديث التلقائي (Auto Update):** متابعة التحديثات والتحسينات البرمجية فور صدورها تلقائياً.
* 🖨️ **طباعة الكروت:** تجهيز الكروت للطباعة المباشرة.

---

## 🚀 طريقة التثبيت والاستخدام

### المتطلبات الأساسية:
1. نظام تشغيل **Windows**.
2. تفعيل خدمة API في راوتر الميكروتك عبر Winbox:
   `IP` -> `Services` -> تفعيل `api` (Port 8728).

---

## 📁 محتويات المستودع

* `RASNetManager.exe`: الملف التنفيذي الرئيسي للبرنامج.
* `AutoUpdate.xml`: ملف تكوين التحديثات التلقائية للنظام.
