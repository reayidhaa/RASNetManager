# 🌐 RASNetManager - نظام إدارة شبكات الميكروتك وتوليد الكروت

![C#](https://img.shields.io/badge/Language-C%23-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)
![MikroTik](https://img.shields.io/badge/RouterOS-API-orange.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

**RASNetManager** هو نظام متكامل ومخصص لإدارة شبكات الميكروتك (MikroTik RouterOS) وتوليد كروت الهوتسبوت (Hotspot Vouchers/Cards) بسهولة وفاعلية، مع دعم ميزة التحديث التلقائي للنظام.

---

## ✨ المميزات الرئيسية (Features)

* 🎫 **توليد الكروت بنقرة واحدة:** إمكانية إنشاء كروت وباقات هوتسبوت بأرقام عشوائية مخصصة (أرقام، حروف، أو مزيج بينهما).
* ⚙️ **إدارة الباقات (Profiles):** التحكم في حدود الوقت (Time Limit) وحجم البيانات (Data Limit) والسرعات.
* 🔌 **الاتصال المباشر مع RouterOS API:** مزامنة سريعة وآمنة مع أجهزة الميكروتك عبر بروتوكول API (Port 8728).
* 🔄 **نظام التحديث التلقائي (Auto Update):** يتضمن نظام تحديث تلقائي يعتمد على ملفات التكوين لضمان تشغيل أحدث نسخة دائماً.
* 🖨️ **طباعة الكروت:** إعداد وتصدير الكروت للطباعة المباشرة بأشكال مختلفة.

---

## 🚀 طريقة التثبيت والاستخدام (Getting Started)

### المتطلبات الأساسية:
1. نظام تشغيل **Windows 10/11**.
2. حزمة **.NET Framework** أو **.NET Desktop Runtime**.
3. راوتر ميكروتك مفعل فيه خيار الـ API عبر المنفذ `8728`.

### إعداد الميكروتك:
قم بتفعيل خدمة API في راوتر الميكروتك عبر Winbox:
`IP` -> `Services` -> تفعيل `api` (Port 8728).

## 📁 هيكلية المستودع (Repository Structure)

* `RASNetManager.exe`: الملف التنفيذي الرئيسي للبرنامج.
* `AutoUpdate.xml`: ملف تكوين التحديثات التلقائية للنظام.
